[Warnings]
If you are reading this that means you are trying to add a custom farm to your world,
or you want two of the same layouts for multiple farms. Please read this carefully.

1.- You can select multiple layouts by simply changing the File option name to the one you want.
2.- Existing buildings or cabins will remain in the farm, go to robin to move or remove them.
3.- Farms have terrain features (like bushes) that you will need to reset using the mod Reset Terrain Features.
4.- You will need to configure the arrival warp coordinates and warps between farms coords in the settings.
6.- To properly setup warp coordinates use the mod LookUp Anything with the option tile lookups enabled.
7.- As the farms in this mod are modified to be entered from determined directions, some farms can't
    be placed at the bottom or the top, read Utils section to know which included farms you can place easily.
8.- As there are a lot of intersections to configure I recommend you to make a copy of the initial config.json,
    just so if something goes wrong you can revert to default without overriding other stuff in the config.

[Utils]
Which farms can be placed at the bottom paths:
  - Wilderness  * Default warp: (40, 2)
  - Forest      * Default warp: (40, 2)
  - Beach       * Default warp: (77, 15)
  - Riverland   * Default warp: (40, 2)
  - All custom farms which by default have a path to Backwoods

Which farms can be placed at top paths:
  - Riverland   * Default warp: (13, 72)
  - Meadowlands * Default warp: (52, 72)
  - Hilltop     * Default warp: (40, 62)
  - All custom farms that by default have a path to Cindersap Forest
